Stack technique

Virtualisation

  • Hyper-V — 2 hôtes physiques, HA/failover
  • Virtual Switch — segmentation interne/externe

Pare-feu / Routage

  • OPNsense v24.7.12_4 sur FreeBSD 14.1
  • pf, Unbound DNS, DHCP (Kea)

VPN & accès distant

  • OpenVPN — site-to-site + road warrior (PKI/TLS)
  • WireGuard — accès mobile léger

SOC — SIEM / XDR / NDR / EDR

  • Wazuh v4.7.5 + OpenSearch — SIEM/XDR
  • Security Onion — Suricata, Zeek, Elasticsearch
  • Huntress — EDR cloud-managé

Monitoring

  • Prometheus v2.51.0 + exporters
  • Grafana — dashboards temps réel

PKI & DNS

  • OpenSSL + CA interne (VPN-CA)
  • Cloudflare + ddclient — DNS dynamique
